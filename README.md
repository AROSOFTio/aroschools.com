# AroSchools

**One Platform. Every School.**

AroSchools is a multi-school Digital Campus SaaS for school websites, student management, academics, fees, portals, HR, finance and school operations.

The repository currently contains the public AroSchools launch site and the foundation for the full SaaS platform.

## Product plan

See **[PLAN.md](./PLAN.md)** for the complete product, pricing, architecture, feature, SEO and implementation plan.

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

Primary public URL: `https://aroschools.com`
